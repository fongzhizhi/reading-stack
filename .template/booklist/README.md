## 🧭 怎么读

> 写**具体行动**，拒绝泛泛而谈——时间、顺序、方法、配合都要落在动作上。

## ✅ 验收标准

> 验收是**做出来才算**，不是翻完最后一页——写可自测的问题或可交付的产物。
> 示范：「随手拿一个陌生八字，能独立判断格局、指出用神喜忌，且其理自洽」「用缓存理论解释 Vue 为什么必须绑 key」。
