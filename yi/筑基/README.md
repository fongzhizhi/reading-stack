## 🧭 怎么读

### 入门路径（递进，非并行）

**第一遍（约3周）**：只读《子平真诠》，逐章推进，不跳读。每章读完必做两件事：①用笔画出该章涉及的五行生克路径图；②套入自己的八字（乙亥 丁亥 丙午 甲午），看能否用刚学的理法说通自己为什么是“杀印相生”。此阶段不求快，若一章三天没啃透，正常，接着读，不留恋。

**第二遍（约2周）**：打开《千里命稿》，遮住韦千里的断语，只读命例和背景。每看一个命例，先用自己的《子平》框架写判断，再对照原书。偏差大的，回翻《子平》相关章节重修。目标：连续验证30个命例，大方向（贫富、贵贱、吉凶）与韦公合拍七成。

**第三遍（约2周）**：插入《增删卜易》，只看“占身命”“占功名”“占求财”三类卦例。每卦必亲手排盘（定世应、装干支），体会五行如何“活变”。同时可拿自己日常小事（“明早能否按时起床”“今天这个需求能准时提测吗”）起卦验证，不强求准，只求能自圆其说。

**第四遍（贯穿全程）**：《了凡四训》不单独划时间。每日晨起或睡前读一章，读时合目三思昨日言行：有无因急躁而口出恶言？有无因自以为是而轻视他人？此为日课，不读完也算读。

### 核心动作

1. **每章必画图**：你是程序员，五行生克于你就是“状态机”。每读一种格局（正官、七杀、食神、伤官……），画一张完整的生克制化路径图，标出顺用、逆用、通关、制化。画不出，等于没读。

2. **先断后看**：读《千里命稿》时，绝不许先看答案。先把断语写在纸上，再翻原书。误差大的，标记章节，日后回炉。

3. **手机放远**：每段专注时间不低于45分钟。你丙火之性最易被碎片信息引动，45分钟内不碰手机，比读两小时边刷边看更出功。

4. **每本读五遍**：一遍如看天书，三遍渐入佳境，五遍方有拍案之悟。此非虚言，筑基期最忌“一遍弃”。

## ✅ 验收标准

完成以下三事，筑基功成，可回寻山人开启下一关：

- [ ] 随手拿一陌生八字（网上随机找、不可选已知案例），能独立判断格局、指出用神喜忌，且用《子平》理法能将判断链条说清楚
- [ ] 为自己当前一个具体事项（如“本月能否完成某项工作目标”）起六爻卦，能完整解释卦象吉凶与应期，且能自圆其说
- [ ] 读《了凡》至“从前种种譬如昨日死”之句，心头能泛起真实触动，而非只作文字过眼

## 🧘 心法与戒律

**心法一：先验己，再验亲，终验天下。**
头一年只拿自己与家人八字反复推演。你知道他们的真实结果，最能修正取用错误。切忌一知半解便去论他人命，那是造业。

**心法二：遇卡合书，起身出门。**
你命局丙火双午，性易躁急。若一章读两遍仍如坠云雾，立合书起身，看窗外绿植（取木气通关），三分钟后再回座，灵光往往在此刻来。强行死磕，火旺焚书。

**心法三：不拘横竖繁简，以“读得舒服”为唯一标准。**
形式是渡河之筏，不是终点。竖繁有竖繁的气韵，横简有横简的方便。选一版你能日日翻开不嫌累的，就是最好的版本。

**戒律：筑基期内，不碰《滴天髓》《三命通会》《渊海子平》。**
此三书虽为经典，但理深象杂，初学读之如入迷宫，反令根基不纯。待筑基成，山人自会在下一阶段带你攻之。

## ⏳ 每日守则

**每日只做三件事：**

1. **晨课（10分钟）**：读《了凡》一章，不求记住，只求读时心静。
2. **正课（1.5小时）**：按上述递进路径，推进《子平》或《千里》或《增删》，不跳步骤。
3. **晚省（5分钟）**：合目回想今日所读，若脑中空空，明日从头再过。

**断则续：**
若因加班、出差中断连续三日以上，归位后第一件事不是追进度，是重读中断前最后一章的标题和核心定义，接上气脉再走。
