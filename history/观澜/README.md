## 阶段：观澜期

> **“观水有术，必观其澜。”** ——《孟子·尽心上》
>
> 看历史长河，不须看清每一朵浪花，先看清几道最大的波澜与转折。本阶段不求博闻强识，但求胸中有坐标，眼中有脉络。目标很简单：**把五千年装进脑子里，不乱。**

## 🧭 怎么读

**阅读路径（按顺序推进）：**

| 阶段 | 时长 | 内容 | 读法 |
| :--- | :--- | :--- | :--- |
| **热身** | 第1周 | 纪录片《中国通史》前20集（远古→秦汉） | 不背，只“混个脸熟”，对朝代顺序产生直觉 |
| **精读** | 第2-4周 | 《中国通史》吕思勉 | 上册速览（文化制度），下册精读（政治史）。边读边画“朝代简表”：每朝用三行字写下“起止时间、开国者、灭亡原因” |
| **长肉** | 第5-6周 | 《明朝那些事儿》前两部 + 《万历十五年》穿插 | 先读《明朝》感受血肉，再读《万历》对比质感。你会发现吕思勉的“骨架”上开始“长肉”了 |
| **随行** | 全程 | 《中国古代文化常识》 | 读到“察举制”“三省六部”“一条鞭法”等术语时翻开查阅。不求读完，只求“用到时能找到” |

**节奏**：每天20-30页，不求快。允许某个朝代读得无聊时跳过，但不允许放下整本书超过三天。

**笔记方式**：拿一张大白纸，画一条时间轴横贯中央。每读一个朝代，把它的名字、起止年份、一件你印象最深的事写在轴上方或下方。观澜期结束时，这张纸就是你的“五千年一眼望穿图”。

## ✅ 验收标准

完成上述阅读后，请试着做以下三件事（写下来，或讲给朋友听）：

1. **五分钟大脉络**：用5分钟，把中国从夏到清的大脉络讲一遍，不遗漏任何主要朝代。不必细说，但顺序不能乱。
2. **三个转折点**：举出三个你印象最深的“历史转折点”，并说一句你认为它为什么关键。
3. **一个兴趣方向**：说出一个你在本阶段最感兴趣、想继续深入的方向——某个朝代、某个人物，或某个制度。

三关皆过之日，**观澜期圆满之时**。

## 🧠 心法与戒律

**三个心法：**

1. **不求全，但求序**。记不住每个皇帝年号是正常的，但搞混唐宋元明清的顺序是不可原谅的。宁可少记，不可记乱。
2. **先见林，再见木**。第一遍读通史，不要停下来死磕某个细节。等整本书读完，你会发现回头再看时豁然开朗。
3. **带着问题读**。每读完一章，问自己一个最简单的问题：“如果我是那个时代的普通人，我的生活会比上一代好吗？”

**三条戒律：**

1. **戒“以今度古”** —— 不要用今天的价值观审判古人，先理解他在当时的环境下为什么那样选择。
2. **戒“英雄史观”** —— 不要太迷恋单个人物的成败。多看看制度、地理、气候、人口这些“沉默的变量”。
3. **戒“半途而废”** —— 中间某个朝代读得无聊了，允许跳过去，但不允许放下整本书超过三天。
