# 📚 Reading Stack

> 欢迎来到我的阅读栈 —— 代码、文明、意识与大道。

作为一个在 `if-else` 逻辑、历史周期律、人性博弈、心理迷宫和古老卦象中反复横跳的平平无奇程序员，我创建了这个仓库，用来安放那些“读过的”和“即将读的”灵魂。

## 🎯 仓库定位

- **📋 书单目录**：按学科分类，记录我看过或准备看的书。
- **🧭 推荐顺序**：有些书需要循序渐进，我会标注出最适合的阅读路径（避坑指南）。
- **✍️ 阅读感想**：每本书都应有回响，记录当时的顿悟、质疑或拍案叫绝。
- **📝 知识笔记**：关键概念摘录，以及如何将它们应用到编程或生活中。

## 🛠️ 维护与愿景

- **定期迭代**：每读完一本，我会第一时间更新笔记并调整推荐顺序。
- **去伪存真**：不收录口水书和纯鸡汤，只保留经得起时间考验（或至少让我头皮发麻）的文本。
- **终极目标**：若干年后，这个 `stack` 能像一台时间机器，让我看到自己认知世界的轨迹是如何一点点“堆叠”起来的。
