# 📚 Reading Stack

> 欢迎来到我的阅读栈 —— 代码、文明、意识与大道。

作为一个在 `if-else` 逻辑、历史周期律、人性博弈、心理迷宫和古老卦象中反复横跳的平平无奇程序员，我创建了这个仓库，用来安放那些"读过的"和"即将读的"灵魂。

## 🌊 怎么逛这个栈

- **大分类 → 书单**：每个学科分类下挂着书单（如 `programming/定锚`、`history/观澜`），一个书单 = 一个阶段的一套书。
- **书单 README 是导航**：读什么、怎么读、通关标准，读完要去哪，都写在里面。
- **books/ 是资料**：每本书一个详情页，书籍介绍 + 如何获取。
- **notes/ 是回响**：每本书一个笔记目录，安放顿悟、质疑与拍案叫绝。
