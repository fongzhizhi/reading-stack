## 阶段：看见看不见的

> 本阶段不追求公式、不追求术语、不追求分清四种市场类型。只追求一件事：**让你对“代价”和“反应”产生生理级别的敏感**。以后听到“免费”二字后颈发凉，看到“限购”第一反应是追问“谁在承担隐性成本”，面对“黑心商家”的说法会本能地追问“那竞争呢？那准入门槛呢？”——这种敏感不是知识，是肌肉记忆。读完后，你站在一条商业街上看到的现象，会比以前多出整整一层。

## 🧭 怎么读

**阅读路径：**

先攻《卧底经济学家》，重点啃第2章（成本）、第3章（价格博弈）、第5章（信息不对称）。这三章是“阵地战”，读一遍，停三天，再读一遍。其余章节扫读即可。
《牛奶可乐经济学》不单独安排时间，只在主战武器卡壳或读累了的时候翻开，当甜点吃。只看现象，先猜答案，猜错了再看答案——猜错的价值比猜对高一倍。

**节奏：**

不设每日页数指标。读到让你皱眉的地方，**立刻放下**，去走一走，或把那个现象代入自己的生活想一想。硬扛只会制造“我学过了”的幻觉。读慢不怕，怕的是眼睛扫过、脑子没动。

**每章三遍循环法：**

1. **扫读**：像看小说，不做笔记不划线。只做一件事——标记出让你“啊？”的地方（惊讶、疑惑、或觉得“这不是废话吗”）。
2. **精读**：回到所有“啊？”标记处，强制代入一个具体场景。读到“机会成本”，就打开备忘录写：“此刻我花1小时读这本书，我的机会成本是什么？”
3. **输出**：关书，假装在饭桌上给一个完全不懂经济学的朋友讲这一章的核心。讲不出，就回去重读第一遍。

**铁律：**

- 读完一章才能读下一章，不许跳章
- 不准边读边查术语词典（上下文会告诉你答案）
- 禁止在这个阶段碰曼昆的《经济学原理》或任何宏观经济新闻分析

**常驻田野侦察任务（读书只占50%，另外50%在这里）：**

在你通勤半径里选一个固定观察对象（水果摊、早餐车、楼下咖啡店）。每周至少记录一次它的变化：价格、排队长度、品类、店员状态。只记录，不分析。等你读完后半段，这些记录会自己开口“说话”。

## ✅ 验收标准

读完最后一页不算通关。以下三个信号出现**至少两个**，才算第一阶段真正结束：

1. 听到朋友说“资本家太黑了”，你不再点头附和，而是会想：“那竞争呢？那准入门槛呢？”
2. 路过一家正在打折的店，第一反应从“去薅羊毛”变成了：“清库存？引流？还是对手在隔壁开了店？”
3. 回看你第一周写的田野侦察日记，能自己看出一个之前完全没意识到的因果链条。

**替代通关路径：** 如果你能把田野侦察对象的故事讲给我听，让我听完觉得“原来这个现象背后是这个逻辑”，也算过关。
