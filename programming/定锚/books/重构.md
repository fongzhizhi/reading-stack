# 《重构》—— 改善既有代码的设计

## 书籍简介

Martin Fowler 的开山之作，定义了「重构」这个词本身。它不是「重写」，而是**在不改变可观察行为的前提下，通过一系列小步手法改善代码结构**。核心内容：坏味道清单（Duplicated Code、Long Method、Feature Envy……）+ 对应的重构手法（Extract Method、Decompose Conditional……）。

第 2 版（2018）最大的变化：**示例语言从 Java 换成 JavaScript**，更贴近前端/全栈工程师的日常；保留第 1 版所有经典手法，并补充了 JS 生态的坏味道（如过长的 callback 链）。

## 为什么是这个版本

- **务必选第 2 版**（封面副标题「改善既有代码的设计」）。第 1 版是 Java 示例，迁移到 TS/React 心理成本高；第 2 版的 JS 示例可以直接对照手头的代码。
- 在「定锚」阶段的角色是**手术刀**：遇到超过 80 行的函数、绕不清的条件判断，直接翻目录找对应手法，现学现卖，不用通读。
